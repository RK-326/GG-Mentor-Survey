Мини-CRM «Менторские пары»

Небольшой, но цельный сервис: назначить пары «ментор ↔ менти» и фиксировать проведённые встречи.

Оплачиваемое · ориентир рабочий день (6–8 часов)Дедлайн — 3 дня с момента получения

Легенда

В образовательной программе есть менторы и участники (менти). Координатор назначает пары «ментор ↔ менти» и фиксирует проведённые встречи. Нужно сделать маленький, но цельный сервис для этого.

Функциональные требования

  1. 1CRUD для менторов и менти (имя, email, направление, статус активен/неактивен).
  2. 2Создание пары ментор ↔ менти. Ограничение: один менти — не более одной активной пары одновременно (валидация на бэке, а не только на фронте).
  3. 3Фиксация встречи внутри пары: дата, длительность, короткая заметка.
  4. 4Экран списка пар с количеством проведённых встреч; фильтр по направлению и по статусу.
  5. 5Простой поиск менторов / менти по имени или email.

Технические требования

  • Backend: FastAPI, база — PostgreSQL, миграции (Alembic или аналог).
  • Frontend: React (можно Vite). Минимальный, но рабочий UI.
  • REST API с осмысленными статус-кодами и валидацией входных данных.
  • Проект поднимается по инструкции из README (приветствуется docker-compose up).
  • Git с внятной историей коммитов.
